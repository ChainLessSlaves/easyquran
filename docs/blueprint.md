# **App Name**:  EasyQuran

## Core Features:

- Quran Text Display: Display the Quran text (Arabic and Bangla translation) verse by verse.
- Surah/Juz Navigation: Enable users to navigate the Quran via Surah and Juz indexes.
- Translation Toggle: Allows user to read the base text, King Fahad Complex translation, or Tanzil translation, as well as the English translation.
- Keyword Search Tool: A tool for the LLM to respond to user input that requests verse by surah name, ayah number, or Bangla/Arabic keyword.
- Theme Toggle: Enable a dark/light mode toggle.

## Style Guidelines:

- The choice of colors are informed by feelings of sacredness, tranquility, and legibility. A light color scheme is recommended to prioritize readability. Background color: Light cream (#FAF9F6).
- Primary color: Desaturated teal (#73AFA5) for a calming and trustworthy feel.
- Accent color: Muted gold (#C0B283) to highlight key elements.
- Headline font: 'Literata', a transitional serif with a literary and slightly formal feel. Body font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look. Note: currently only Google Fonts are supported.
- Clean and modern responsive layout, prioritizing Bangla text. Use a clear visual hierarchy to guide the user.
- Simple and intuitive icons for navigation and features. Ensure icons are culturally appropriate.
